# Thematic Markov Generator

A project combining two previous modules I have made, a markov chain text
generator and an extractive text summarizer. The goal of this program is
to generate text using markov chains built from a summarized source. 

## Running This Program

You will need to run `pip install requirements.txt` as well as including
both `markov.py` and `summarizer.py` from the relevant folders in this
repository. Additionally, as `summarizer.py` makes use of nltk, you will
need to install the nltk components by running `python3 nltk_modules.py`,
which is also found in the Summarizer directory.
